*Vitalhub — Multi-Tenant Hospital Operations, Triage & Billing System*
Is a full-stack, multi-tenant clinical operations and hospital management platform built with Flask,
SQLAlghemy, MySQL 8+ / SQLite, React, Vite, and Tailwind CSS.
It models the complete outpatient care lifecycle—from platform-level hospital onboarding and patient registration,
through nurse triage, doctor consultation, and itemized billing, up to senior management oversight—enforcing
strict tenant isolation and role-based access control across every layer of the stack.
